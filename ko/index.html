도구가 모두 브라우저에서 동작하는 이유

작은 도구는 일을 단순하게 만들어야지, 데이터를 넘겨주는 단계를 하나 더 만들어서는 안 됩니다. ZenFlow Tools는 이미 탭에서 실행 중인 자바스크립트로 필요한 작업을 처리합니다. 타이머는 기기의 시각을 비교하고, 비밀번호 도구는 브라우저에 암호학적으로 안전한 난수를 요청하며, 비교 도구는 두 문자열을 메모리 안에서 비교합니다. JSON 도구는 브라우저의 파서를 쓰고, SVG 도구는 입력한 마크업만 다룹니다. 이 중 어떤 작업에도 계정 데이터베이스나 문서 업로드 대기열이 필요하지 않습니다.

이 설계는 개인정보의 경계를 실제로 바꿉니다. 텍스트, 코드, 초안, 벡터 파일은 결과를 직접 복사하거나 내려받지 않는 한 기기에 남습니다. 페이지 자체는 호스팅, 글꼴, 광고를 위한 일반적인 요청을 보내며, 이는 개인정보처리방침에서 설명합니다. 하지만 각 편집기 안의 내용은 그 요청에 실리지 않습니다. 도구를 쓰는 동안 브라우저의 네트워크 패널을 열면 직접 확인할 수 있습니다.

브라우저 안에서 처리하면 불필요한 기다림도 사라집니다. 입력과 결과 사이에 업로드 진행 표시, 변환 대기열, 로그인 화면이 없습니다. 대부분의 도구는 페이지가 열린 뒤에는 잠시 연결이 끊겨도 계속 동작합니다. 다만 결과는 브라우저의 자바스크립트 엔진, 시계, 지역 설정, 메모리 한도, 지원 기능에 따라 달라질 수 있습니다. 이런 한계는 미완성 기능이 아니라 설계상의 조건입니다.

이 사이트는 빠른 추정치를 공식 감사처럼 포장하지 않습니다. 비밀번호 해독 시간 표시는 모델이고, cron 미리보기는 선택한 시간 기준을 따르며, 소셜 카드는 실제 화면을 근사한 것이고, 읽기 시간은 계획을 돕는 참고치입니다. 중요한 값을 실제로 쓸 시스템에서 확인하는 방법은 가이드(영문)에서 다룹니다. 빠른 로컬 계산과 분명한 확인 절차를 함께 갖추면, 브라우저 도구는 버튼 한 번 누르는 것 이상의 쓸모를 갖게 됩니다.

이 사이트를 관리하는 방식

모든 도구는 자기 페이지에 담긴 코드로만 동작하며, 그 코드는 GitHub 저장소에 공개되어 있어 어떤 변경이든 확인할 수 있습니다. 결함은 발견되는 대로 고칩니다. 예를 들어 2026년 11월에는 알림 요소가 빠져 글자 수 세기의 예시 넣기 기능이 오류를 냈고, 뽀모도로 타이머의 소리와 단축키가 동작하지 않았으며, 도구 페이지 세 곳에서 공통 머리말과 바닥글이 잘못 표시되었습니다. 세 문제 모두 수정했습니다. 도구의 동작이 바뀌면 그 페이지의 ‘최종 업데이트’ 날짜도 함께 바뀝니다.

가이드는 키워드를 노리기보다 도구를 둘러싼 판단을 돕기 위해 씁니다. 관례와 보장을 구분하고, 직접 해 볼 수 있는 실험을 담으며, 해당하는 도구로 다시 안내합니다. 오류 제보는 문의 페이지나 GitHub Issues로 받습니다. 페이지, 브라우저, 공유해도 안전한 입력, 기대한 결과, 실제 결과를 함께 적어 주시면 가장 도움이 됩니다.
