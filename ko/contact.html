문의

버그, 접근성 문제, 문서 오류, 보안 우려, 제휴 문의를 확인하는 채널로 보내 주세요.

보낼 내용

버그 제보, 문서 정정, 접근성 문제, 광고·제휴 문의, 책임 있는 보안 제보를 모두 받습니다. 좋은 버그 제보에는 페이지, 브라우저와 운영체제, 재현 단계, 기대한 결과, 실제 결과가 들어갑니다. 비밀이나 개인정보가 없는 작은 예시만 공유해 주세요.

접근성 의견은 불편했던 컨트롤이나 읽기 순서를 적어 주시고, 괜찮다면 사용한 보조 기술도 알려 주세요. 보안 제보는 제목에 SECURITY를 넣고, 내용이 악용될 수 있다면 공개 이슈 대신 이메일을 이용해 주세요.

이메일

wuyung027@gmail.com으로 보내 주세요. 메시지는 보통 영업일 기준 2~3일 안에 확인합니다. 복잡한 기술 문제는 조사에 더 오래 걸릴 수 있지만, 간결한 재현 단계가 있으면 훨씬 빨라집니다.

GitHub Issues

민감하지 않은 버그와 기능 요청은 GitHub Issues를 이용해 주세요. 먼저 기존 이슈를 검색하고, 내용을 알 수 있는 제목을 쓰고, 스크린샷·코드 예시·로그에 기밀 정보가 들어가지 않게 해 주세요.

개인 자료에 관한 안내

도구는 편집기 입력이 브라우저 안에 머물도록 만들었지만, 이메일이나 공개 이슈는 별개의 소통 채널입니다. 비밀번호, API 키, 고객 기록, 비공개 문서, 사내 소스 코드, 가리지 않은 로그를 첨부하지 마세요. 민감한 값은 문제를 그대로 재현하는 무해한 예시로 바꿔 주세요.

제보는 영향도와 재현 가능성을 기준으로 분류합니다. 확인된 기능·접근성 결함은 코드 수정과 페이지 날짜 갱신으로 이어질 수 있습니다. 기능 제안은 작고, 로컬에서 동작하며, 계정이 필요 없는 도구라는 방향에 맞는지 검토하며, 제안했다고 해서 반드시 구현되는 것은 아닙니다.
