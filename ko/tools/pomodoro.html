나만의 배경을 새롭게 배경음
이번 방문에서 완료한 집중 세션 0회 · 작은 걸음이 쌓여 갑니다.

이 타이머가 정확히 하는 일

네 개의 탭은 길이가 고정되어 있습니다. 뽀모도로는 25분, 짧은 휴식은 5분, 긴 휴식은 15분 동안 진행되고, 스톱워치는 0부터 시간을 셉니다. 시간을 직접 정하는 기능은 없으며, 집중 블록이 끝난 뒤 휴식으로 자동 전환되지도 않습니다. 카운트다운이 0에 도달하면 화면에 “세션 완료. 수고한 만큼 푹 쉬세요.” 또는 “휴식 완료. 새로 시작할 준비가 됐나요?”라는 메시지가 표시되고, 집중 블록이 끝난 경우에는 세션 수에 1을 더하며, 짧은 세 음 차임(C, E, G, 약 0.2초 간격)이 울립니다. 시작 버튼을 누를 때 오디오가 활성화되지만, 기기가 음소거 상태이거나 자동 재생 설정이 엄격하면 여전히 소리가 나지 않을 수 있으므로 화면에 표시되는 메시지가 가장 확실한 신호입니다.

백그라운드 탭과 절전 모드

남은 시간은 틱을 하나씩 세는 방식이 아니라, 화면을 갱신할 때마다 기기 시계를 기준으로 다시 계산합니다. 탭이 숨겨지거나 컴퓨터가 절전 상태에 들어가도 카운트다운은 실제 시간과 같은 속도로 흐르고, 탭이 다시 보이는 즉시 화면이 따라잡습니다. 브라우저는 백그라운드 탭의 타이머를 느리게 실행하기 때문에 세션 종료가 조금 늦게 감지될 수 있으며, 세션 도중 시스템 시계를 바꾸면 결과도 달라집니다.

세 가지 소리를 만드는 방식

오디오 파일은 내려받지 않습니다. 각 소리는 페이지 안에서 생성한 5초 분량의 무작위 노이즈를 Web Audio 필터에 통과시켜 반복 재생합니다. 빗소리는 1.6 kHz 로우패스 필터를 거치고, 모닥불은 부드럽게 다듬은 저주파 노이즈에 650 Hz 로우패스를 적용하고 가끔 탁탁 튀는 소리를 섞으며, 백색소음은 필터 없이 더 낮은 음량으로 재생합니다. 여러 소리를 겹쳐 틀 수 있고, 타이머 작동 여부와 관계없이 계속 재생되며, 볼륨 슬라이더는 모든 소리의 크기를 함께 조절합니다. 완료 차임은 이 슬라이더의 영향을 받지 않습니다.

저장하지 않는 것

방문과 방문 사이에 저장되는 것은 없습니다. 세션 수는 메모리에만 있어 새로고침하면 0으로 돌아가고, 기록이나 통계 화면은 없으며, 다른 모드 탭을 고르거나 초기화 버튼을 누르면 확인을 묻지 않고 해당 모드를 처음 길이부터 다시 시작합니다. 이 페이지는 브라우저 알림을 사용하지 않으므로, 백그라운드 탭에서 타이머가 돌아가고 있어도 시스템 알림은 뜨지 않습니다.

키보드

Space는 시작 또는 일시정지, R은 초기화, F는 집중 보기 전환이며, Escape를 누르면 집중 보기에서 나옵니다. 집중 보기는 사이트 헤더, 푸터, 배경음 패널을 숨기고 브라우저에 전체 화면을 요청합니다. 버튼, 링크, 입력 필드에 키보드 포커스가 있는 동안에는 단축키가 무시되므로, 다른 곳에 입력하다가 타이머가 시작되는 일은 없습니다.
